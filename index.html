Step 1 — Scoring

Raw Attention Relevance Scores

Computed via dot products (QKᵀ). High dot product = strong directional alignment in vector space.

Query Token: "it"
Score(i, j) = Qᵢ · Kⱼᵀ

These numbers measure raw alignment. Notice that they can be arbitrary magnitudes and do not yet sum to 100%.

Step 2 — Softmax

From Scores to Normalized Weights

Softmax exponentiates and divides by the sum, converting raw scores into probabilities summing to 1.00.

Softmax Transformation
αᵢ = exp(sᵢ) / ∑ exp(sⱼ)
Total Sum = 1.00 (100%)

Higher scores get amplified exponentially. "animal" captures 65% of the total attention budget!

The Core Mechanism

The Three Pieces Behind Attention: Q, K, V

Input embeddings are linearly projected into three distinct vectors, each with a specialized role.

Q
Query
"What am I looking for?"
Represents the current token probing the rest of the sentence for relevant context.
K
Key
"What do I offer for matching?"
Represents a label or index that candidate tokens present to be matched against the Query.
V
Value
"What content do I pass forward?"
Contains the actual semantic information that will be weighted and merged into the final vector.
Q × Kᵀ = Relevance Score | Softmax(Score) = Attention Weights | Weights × V = Contextual Vector

Formal Mathematics

The Attention Formula

Attention(Q, K, V) = Softmax ( Q Kᵀ / √dₖ ) V
Q Kᵀ
Relevance Scores

Computes pairwise dot product similarities across all tokens.

√dₖ
Scaling Factor

Prevents extreme scores and vanishing gradients in deep networks.

Softmax
Attention Weights

Converts raw logits into a valid probability distribution summing to 1.

× V
Information Mixing

Blends token features weighted by their calculated attention relevance.

Computational Limits

Where Attention Gets Expensive

Every token compares with every token: an O(N²) quadratic scaling that challenges long sequences.

🔥
Quadratic Compute Cost O(N²)
Pairwise token comparisons scale with the square of sequence length.
💾
High Memory Footprint
Storing the full attention matrix across dozens of layers stresses GPU VRAM.
📚
Resource Intensive
Requires clusters of dedicated accelerators (TPUs/GPUs) for training.
🧩
Interpretability Nuance
Attention weights show correlation and focus, but don't always explain full causality.
